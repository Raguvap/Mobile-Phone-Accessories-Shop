# Mobile Phone Accessories Shop

Static Tailwind CSS and vanilla JavaScript template for a premium mobile phone, accessories, and repair shop.

## Pages

- `index.html`
- `pages/about.html`
- `pages/products.html`
- `pages/product-details.html`
- `pages/services.html`
- `pages/contact.html`
- `pages/404.html`

## Assets

- `assets/css/style.css` contains the custom electronics retail visual system.
- `assets/js/main.js` handles the mobile menu, footer year, and demo form messages.
- `assets/images/phone-hero.svg` is the local product hero artwork.
